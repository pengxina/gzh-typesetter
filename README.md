# 公众号图文排版工具

一个**纯前端、单文件**的公众号图文排版助手：把 Markdown 文字自动排成公众号样式，一键复制到公众号编辑器，样式完整保留。

## 功能

- **Markdown 排版**：`#` 大标题、`##` 小标题、`>` 引用、`-`/`1.` 列表、`---` 分隔线

- 
- **6 套主题**：知识 / 杂志 / 文艺 / 卡片 / 原理 / 地道，一键切换
- **文字样式**：加粗、斜体、下划线、删除线、高亮、颜色、字号（选中文字后点按钮即生效，再点一下取消）
- **图文混排**：`![图注](图片链接)` 插入网络图片；`![v:标题](腾讯视频链接)` 插入视频
- **数学符号**：`$180^\circ$` → `180°`，`$a^2$` → `a²`，直接识别 LaTeX 写法
- **全局首行缩进**：一键开关
- **双栏编辑**：左侧写 Markdown，右侧实时预览；手机上可切换编辑/预览，两边工具栏一致
- **一键复制**：排版完成后点「复制到公众号」，直接粘贴到公众号编辑器

## 使用方法

1. 打开页面（电脑浏览器体验最佳，手机也可用）
2. 在左侧粘贴你的文章文字，支持 Markdown 语法
3. 右侧实时预览排版效果，需要时用工具栏调整样式
4. 点「复制到公众号」，到公众号后台直接粘贴

**图片说明**：

- 网络图片链接（如 `![图注](https://xxx/图片.jpg)`）粘贴到公众号可直接显示，微信会自动转存
- 本地图片粘贴到公众号会被微信过滤，需要在公众号后台重新上传

**视频说明**：粘贴腾讯视频链接可显示；本地视频需在公众号后台「素材库」上传

## 技术说明

- 单文件 HTML（CSS/JS 全部内联），无任何外部依赖，`file://` 直接打开也能用
- 纯前端运行，不上传你的任何内容

发布后把链接发到公众号、小红书、朋友圈，任何人都能直接用。
